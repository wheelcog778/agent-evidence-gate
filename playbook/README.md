# 多智能体避雷包

给刚接触 agent、手上只有轻量模型的人。**不是教程合集，是踩坑记录 + 一个能跑的最小实现。**

> **核心主张：把不确定性压进结构里，而不是指望模型自己稳。**
> 做到位了，轻量模型也能交付；做不到，最强的模型也只是让你更快地产生不可信的东西。

## 从这里开始

1. **`00-先读这个.md`** — 15 分钟跑通 + 为什么是这三层
2. **`docs/避雷清单.md`** — 21 条真实事故，每条有出处和修法
3. **`docs/轻量模型守则.md`** — 12 条结构约束，让弱模型也能交付
4. **`docs/验收清单.md`** — 交付前照着打勾
5. **`starter/`** — 能跑的最小任务总线（30 项测试全过，纯标准库）

## 快速验证

```bash
cd starter
python bus.py init
python selftest.py      # 期望 30/30 PASS
```

**60 秒看完全部行为**（不用读文档）：

```bash
bash demo.sh
```

依次演示：幂等、拒绝未认领执行、隔离执行、证据长什么样、改一个字节被拦、审批门、上下文预算。全部真跑。

## 不包含

- 具体模型的 API 调用（你自己接，`starter/demo/agent_verify.py` 里有示例）
- 多机部署、消息队列、Web UI
- 任何密钥、任何私有数据

## 已知边界

`starter/` 能保证：任务不会双跑、崩溃能回收、产物必须带可复算的证据、审批没过不能执行。
`starter/` 不能保证：产物是"哪条命令"生成的——manifest 由 agent 写，执行器只能保证外层进程成功退出且自己的日志不可改。

这个边界写在 `docs/避雷清单.md` 第 21 条，没有藏。
